# D04 — guide testeur (parcours membre connecté)

Durée ~10 min. **Ne pas** ouvrir `?demo=1` / « Entrer en démo » pour cette recette.

## Prérequis

- URL Test/Preview ou alias connecté fourni par l’organisateur (noter l’URL + SHA).
- Créer ton propre compte email (mot de passe 8+ caractères) via **Créer un compte**, ou te reconnecter.
- Mode connecté: pas de catalogue démo mélangé.

## Étapes

1. **Connexion** — Accueil auth → **J'ai déjà un compte** (ou inscription) → email + mot de passe → tu arrives dans les onglets.
2. **Trouver une sortie** — onglet Accueil → liste des sorties API (ex. Sortie testeurs — Corniche si seed présente).
3. **Ouvrir le détail** — vérifier type/workout, allure, horaire, lieu / meeting point, distance/places.
4. **Rejoindre** — CTA d’inscription → toast de succès **seulement** si l’API accepte. En cas d’erreur API, un message d’échec doit apparaître (pas d’inscription locale silencieuse).
5. **Mes sorties** — onglet Mes Sorties → la sortie apparaît en confirmée avec statut d’inscription réel.

## Hors scope de cette recette

- OTP / SMS
- Mode démo jury
- Promote production / App Store

## Signaler un défaut

Navigateur ou appareil + capture + étape (U1–U5) + URL + heure. Remplir `D04-defect-log.md`.
